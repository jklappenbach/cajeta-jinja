# cajeta-jinja

A Jinja2-compatible template engine for cajeta: lexer, parser,
interpreter, and the filter/test library, over a `JsonValue`-shaped
context. Extracted from `cajeta-llama` Unit 13.

- Spec: `specs/cajeta-jinja-spec.md` (compiler repo)
- Grammar: `grammar/Jinja.g4` is the normative contract; the parser is
  hand-written recursive descent (ANTLR4 has no cajeta target).
- Correctness: fixture corpus with byte-exact references GENERATED by
  real Jinja2 (`tools/gen_fixtures.py`, pinned version) — expectations
  are never hand-written.

## Test

    ./run-tests.sh            # CAJETA=<compiler> to override
    python3 tools/gen_fixtures.py   # regenerate references (review diff!)

Consumers: `cajeta-llama` (chat templates, autoescape off) and later
`cajeta-http` (HTML, autoescape on).
